# Renewable Energy & Sustainability Dashboard 🌍⚡

## 🔗 Live App
👉 **[Click here to open the interactive dashboard](https://abigailamoah.shinyapps.io/FINALPROJECT/)**

## Project Overview
An interactive R Shiny dashboard that allows users to visually 
explore global renewable energy and sustainability trends using 
the World Sustainability Dataset.

## Features
- 📊 Interactive data visualizations across multiple tabs
- 🗺️ Global sustainability metrics explorer
- ⚡ Renewable energy trends analysis
- 🎛️ User-controlled inputs for customized exploration

## Dataset
- **Source:** World Sustainability Dataset (Kaggle) — publicly available
- **Coverage:** Global sustainability and energy metrics

## Technical Stack
| Tool | Purpose |
|------|---------|
| **R Shiny** | Interactive web application |
| **ggplot2** | Data visualization |
| **dplyr** | Data manipulation |
| **R Markdown** | Documentation |
